# 0002 プラグインとしての配布

- 日付: 2026-10-26
- 状態: 採用（ローカルマーケットプレイスで検証済み）

## 解消したい問題

従来の相対シンボリックリンクは、このリポジトリ内で Codex と Claude Code にスキルを見せるためのものだった。別の製品リポジトリで利用するには、ユーザーがスキルを手動で配置する必要があった。

## 決定

このリポジトリのルートをプラグイン本体とし、`skills/nikostack/` を唯一のスキル原本に保つ。ルートの `plugin.json` は Codex 向けのポータブルマニフェスト、`.claude-plugin/plugin.json` は Claude Code 向けの互換マニフェストとする。両 CLI のマーケットプレイスにはルートディレクトリを指定する。スキルの内容は複製しない。

インストールは利用者が明示的に行う。プラグインは共通手順だけを提供し、製品固有の仕様、検証コマンド、認証情報、MCP サーバーは含めない。製品リポジトリの指示が作業の基準である。

## 確認と残る課題

Codex CLI 0.164.0 と Claude Code 2.1.310 で、ローカルマーケットプレイスから `nikostack@nikostack` をインストールできた。Codex のキャッシュ内のスキルが原本と一致し、Claude Code はスキル 1 件を認識した。検証用のインストールとマーケットプレイス登録は削除した。

実際の製品リポジトリでの依頼遂行や、GitHub のリモート URL からのインストールはまだ確認していない。公開ディレクトリへの提出には別途、ライセンスなどの公開要件を満たす必要がある。
